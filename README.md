# kushals-weekly-shortage-tracker
Weekly inventory shortage spike tracker for Kushals Retail

**Live tracker:** https://yallappat-spec.github.io/kushals-weekly-shortage-tracker/Weekly_Shortage_WoW_Tracker_1.html

Data is read directly from the team's Google Sheet in the browser and refreshes automatically every 5 minutes. Shortages carry forward week to week (and across months) until a Stock Audit resets the count.
